# Nirvana Control

A lightweight, bloat-free, privacy-first Android companion app for **boAt Nirvana Space** TWS earbuds.

## Features
- **Pure Native & Lightweight**: Built with modern Jetpack Compose and Material 3 (< 4 MB).
- **100% Offline & Private**: Zero trackers, zero cloud accounts, no internet permission.
- **Full Hardware Control**:
  - Live battery reporting for Left bud, Right bud, and Case.
  - Active Noise Cancellation (ANC ON / Transparency / Normal).
  - 360° Spatial Audio with Head Tracking and Recenter calibration.
  - BEAST™ Low Latency Gaming Mode.
  - 10-Band DSP Equalizer + Custom profiles.
  - Independent Touch Gesture remapping for Left & Right buds.
- **Android System Integration**: Quick Settings Tiles & optional zero-resource auto-wake.
