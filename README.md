# Nirvana Control

A lightweight, bloat-free, privacy-first Android companion app for **boAt Nirvana Space** TWS earbuds (< 4 MB).

## Architecture & Features

- **Zero Bloat & 100% Offline**: No internet permission, zero telemetry, zero accounts.
- **Hardware Bluetooth SPP Protocol**:
  - Direct RFCOMM socket to Bluetrum Bluetooth 5.3 SoC.
  - Sub-millisecond latency commands with 5-byte framing protocol.
- **Features**:
  - 🔋 **Live Tri-Battery Meters**: Left Earbud, Right Earbud, and Charging Case with charging status.
  - 🔇 **3-Way ANC Control**: Active Noise Cancellation (ANC ON), Transparency Mode, and Normal/Off.
  - 🎮 **BEAST™ Mode**: Low-latency gaming switch.
  - 🎚️ **10-Band DSP Graphic Equalizer**: 31Hz - 16kHz sliders, hardware presets, and a guided hearing threshold calibration test.
  - 🎧 **Spatial Audio Studio**: 360° spatial audio modes, visual 3D head-orientation tester, and 1-tap haptic Recenter calibration.
  - 👆 **Interactive Gesture Remapping**: Independent Left & Right bud touch mapping for Single, Double, Triple, and Long Press gestures with Accidental-Touch Guard.
  - ⚡ **Android System Integration**: Quick Settings Tiles & optional compact status notification with zero background idle resource consumption.
  - 📡 **Full Bluetooth Discovery**: Live RSSI radar scanner.
  - 🖤 **Material 3 + True-Black OLED**: Clean dynamic theming optimized for battery savings.
