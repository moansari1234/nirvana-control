# Nirvana Control

A lightweight, bloat-free, privacy-first Android companion app for **boAt Nirvana Space** TWS earbuds (< 4 MB).

## Architecture & Features

- **Zero Bloat & 100% Offline**: No internet permission, zero telemetry, zero accounts.
- **Hardware Bluetooth SPP Protocol**:
  - Direct RFCOMM socket to Bluetrum Bluetooth 5.3 SoC.
  - Sub-millisecond latency commands with 5-byte framing protocol.
- **5-Tab Bottom Navigation**:
  - 🏠 **Dashboard**: Live tri-battery meters (Left, Right, Case), 3-way ANC control, BEAST™ gaming mode.
  - 🎚️ **Equalizer**: 10-band DSP sliders (31Hz - 16kHz), hardware presets, and a guided hearing calibration test.
  - 🎧 **Spatial Studio**: 360° spatial audio modes, visual 3D head-orientation tester, and 1-tap haptic Recenter calibration.
  - 👆 **Gestures**: Independent Left & Right bud touch mapping for Single, Double, Triple, and Long Press with Accidental-Touch Guard.
  - ⚙️ **Settings**: Auto-wake configuration, background service toggle, in-ear detection, device scanner, and backup.
- **Android System Integration**: Quick Settings Tiles & optional compact status notification with zero background idle resource consumption.
- **Bluetooth Discovery**: Live RSSI radar scanner.
- **Material 3 + True-Black OLED**: Clean dynamic theming optimized for battery savings.
